# walmart-recommendations · Recommendation Service

ML-powered product recommendation gRPC service. Returns a list of related products for a given item, used on the product detail page.

## Stack
- **Language:** Python 3.11
- **Framework:** gRPC (`grpcio`)

## API
Implements `RecommendationService` from `demo.proto`:
- `ListRecommendations(ListRecommendationsRequest) → ListRecommendationsResponse`

Recommendations are generated by fetching the full product list from the catalog service and randomly sampling products not already viewed — a simple collaborative-filter stub suitable for demo load.

## Running locally
```bash
pip install -r requirements.txt
python recommendation_server.py
```
Service listens on port `8080` by default (`RECOMMENDATION_SERVICE_PORT`).

## Dependencies

| Env var | Service |
|---|---|
| `PRODUCT_CATALOG_SERVICE_ADDR` | walmart-product-catalog |
